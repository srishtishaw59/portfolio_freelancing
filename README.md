> **Data Analyst • Storyteller with Data**

## 🌟 Overview
A modern, responsive multi-page portfolio crafted with liquid glassmorphism, multi-zone twilight ambient lighting, and high-performance micro-interactions.

### 📄 Pages Included:
- **Home (`index.html`)**: Hero section with interactive focus & impact snapshot cards, analytical capabilities, featured project showcase, and connect CTA.
- **About (`about.html`)**: Analytical philosophy, core background, 4-phase milestone journey timeline, and analytical passions.
- **Projects (`projects.html`)**: Interactive category filter pill bar and 7 real-world analytics repositories with live GitHub links and metrics.
- **Skills (`skills.html`)**: Core competency domains with glowing proficiency meters and an interactive 12-tool technology grid.
- **Contact (`contact.html`)**: Direct communication channels (LinkedIn, GitHub, Location, Availability), interactive glassmorphic inquiry form, and FAQ expectation cards.

---

## 🛠️ Tech Stack & Design System
- **Semantic HTML5 & Modern CSS3**: Custom design system in `style.css` featuring liquid glassmorphism (`backdrop-filter: blur`), CSS variables, and responsive media queries.
- **Vanilla JavaScript (`script.js`)**: Interactive right-side scroll percentage dialer (`0%` to `100%`) with circular SVG progress ring, click-to-navigate track, and drag scrolling.
- **Typography**: Google Fonts (`Playfair Display`, `Caveat`, `Poppins`, `Great Vibes`).
